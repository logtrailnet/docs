## Automatic Tool Integration

If you are using an AI-powered IDE like **Cursor** or **Windsurf**, simply point it to this site. These tools will automatically look for the `/llms.txt` file at the root to understand how to help you write code for Logtrail.

```bash
# Example for tools that accept a documentation URL
https://docs.logtrail.net/llms.txt
```
